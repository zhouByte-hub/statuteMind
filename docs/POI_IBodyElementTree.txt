XWPFDocument
├─ 主正文 bodyElements：List<IBodyElement> 【顺序就是文档流顺序！】
│  ├─ XWPFParagraph（段落，IBodyElement）
│  │  ├─ runs: List<XWPFRun> 【同一段样式文本块】
│  │  │  ├─ text、换行、分页符、域、注释标记
│  │  │  ├─ getEmbeddedPictures(): List<XWPFPicture> 【⚠️ 图片挂在这里】
│  │  │  │  │  【⚠️ XWPFPicture 不是 IBodyElement！getBodyElements() 永远遍历不到，解析图片必须走 段落→run→embeddedPictures 这条路】
│  │  │  │  ├─ getCTPicture(): CTPicture 【XmlBeans 层，对应 XML <pic:pic>】
│  │  │  │  │  ├─ nvPicPr（非可视属性区）
│  │  │  │  │  │  └─ cNvPr: id / name / descr 【descr = 替代文字，Word“可选文字”面板】
│  │  │  │  │  ├─ blipFill → blip 的 r:embed="rIdX" 【关系 ID，指向图片资源】
│  │  │  │  │  └─ spPr（尺寸、形状）
│  │  │  │  └─ getPictureData(): XWPFPictureData 【⚠️ 字节本体走这里】
│  │  │  │     ├─ getData(): byte[]、getFileName()、suggestFileExtension()
│  │  │  │     └─ 经 r:embed 关系间接指向 /word/media/imageN.png
│  │  │  └─ CTRPr：run样式（字体、颜色、加粗）
│  │  └─ CTPPr：段落样式（对齐、缩进、行距、样式 styleID）
│  ├─ XWPFTable（表格，IBodyElement）
│  │  ├─ rows: List<XWPFTableRow>
│  │  │  └─ cells: List<XWPFTableCell> 【⚠️ 它也实现 IBody！】
│  │  │     └─ bodyElements: List<IBodyElement>（单元格内部递归放段落、嵌套表格，
│  │  │        所以单元格里的图片同样在 段落→run→embeddedPictures）
│  └─ XWPFSDT（SDT 内容控件，IBodyElement，富文本控件）
│
├─ 页眉页脚：XWPFHeaderFooterPolicy
│  ├─ XWPFHeader / XWPFFooter 【同样实现 IBody，内部也是 IBodyElement】
├─ 脚注、尾注：XWPFFootnote / XWPFEndnote 【同样 IBody】
├─ 图片资源池：getAllPictures(): List<XWPFPictureData> 【全文档二进制资源，存于 media/】
│  【⚠️ 与 XWPFPicture 的区别：PictureData 是字节本体，Picture 是文档结构节点（可取
│     尺寸、alt text），两者通过 r:embed 关系 ID 关联】
├─ 超链接、批注、书签、样式、主题、文档设置
└─ CTDocument（底层XmlBeans原生对象，对应 w:document）
