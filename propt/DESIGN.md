# DESIGN.md — statuteMind 原型视觉系统

方向：**百度式搜索引擎界面**（2026-10-25 用户定调，取代旧「定向推理图」地图风）——白底、居中品牌 + 大搜索框；搜索/判断后搜索框收窄吸顶，结果列表呈现在下方。全部界面为单文件 `index.html`，仅 Google Fonts 外链。

## 字体

- 全站 `Noto Sans SC` 400/500/700/900（Google Fonts），品牌字重 900
- 字号阶梯：首页品牌 50（移动 38）/ 结果标题 16.5 / 正文与摘要 14 / 出处行 12.5 / 元标签 11–13
- 数字一律 `font-variant-numeric:tabular-nums`

## 布局（两态 morph）

- **首页态**：顶栏（导航 + 演示数据徽标，品牌隐藏）→ 居中列 880px：天平 logo + `statuteMind`（statute 墨色 / Mind 蓝）→ 副题 → 模式切换 tab（搜法条 | 判行为，蓝下划线选中）→ 大搜索框（620px，2px 蓝描边，右侧同高蓝色按钮）→ 示例 chips → 最近检索。页面自然滚动
- **结果态（SERP）**：视图加 `.compact` 类 —— 品牌大字/tabs/chips/最近检索隐藏，`.sboxRow` 变 `position:sticky top:0` 吸顶（白底、下边线、42px 窄框），左侧出现小 logo（点击回首页态）；下方 720px 结果列
- **判行为（左右双面板）**：`#/judge` 为两栏 — 左面板 400px（标题 + 行为描述 textarea + 开始判断按钮 + Ctrl/⌘+Enter 提示 + 示例 chips + 免责注脚）；右面板为**分析图谱**：四列节点图「行为(蓝底根节点) → 定性 → 主条文/关联条文 → 处罚 & 风险」，SVG 贝塞尔连线 + 箭头按 `--d` 错峰描线（`pathLength=1` dash 动画），节点卡按列错峰 `rise`；点击节点 → 底部详情卡显示结构化键值行，法条节点附「在知识库查看」「去检索」跨视图跳转；未收录行为在右面板显示 notice + 示例 chips；<960px 上下堆叠、连线隐藏、节点纵向排列
- **知识库**：单列 760px，标题 + 模拟上传按钮（虚线框）+ 分类 chips（含计数，选中实心蓝）+ 按组列表（组头蓝色竖条）；条目平铺全文，尾部「判相关行为」「去检索」跳转
- 三视图 hash 路由：`#/search`（默认）· `#/judge` · `#/library`，顶栏导航 + tabs + 结果内链接互跳；深链 `?q=关键词`（检索）、`?j=jid`（判断）
- 页脚免责「演示数据，仅供参考，不构成法律意见」常驻

## 动效（服务理解，不喧宾夺主）

- 首页加载：品牌 → 搜索框 → chips → 最近检索依次 `rise` 错峰 60–80ms
- 搜索提交：搜索中 meta 文案 + 620px 蓝色有限进度条 `loadgrow .7s`（`scaleX` 单次，无无限循环），700ms 后结果按 `--i*90ms` 错峰 `rise`
- 分析图谱：连线 `edgedraw .55s` 逐条错峰描线 + 箭头，节点按列 `--i*120ms` 错峰 `rise`；窗口 resize / 字体就绪后重算连线坐标
- 知识库定位跳转：目标行 `flashbg` 蓝底淡出 1.2s + `scrollIntoView`
- 缓动 `--ease: cubic-bezier(.16,1,.3,1)`；`prefers-reduced-motion: reduce` 下全部动画/过渡关闭（headless 验收用 `--force-prefers-reduced-motion` 取终态截图）
- 明令禁止：无限 marquee/脉冲动画；演示徽标用静态圆点

## 无障碍

- 全文字色 ≥4.5:1（品牌蓝特意从 #4E6EF2 加深为 #3D5CE5，占位符加深为 #6E7683）
- 键盘：输入框 Enter 提交、全按钮原生可达、`:focus-visible` 2px 蓝环
- 状态通知 `role="status"`（aria-live）；logo/图标均 `aria-hidden` 或带 aria-label
